# MSIS — Merrowfield Student Information System

A department-scoped student information system for a fictional university, built as a portfolio project with React, TypeScript, Supabase and an ASP.NET Core admin API on .NET 10.

> **Status:** work in progress, Milestone 0 (project setup). A full README covering the architecture, security model, roadmap and local setup is being written as part of this milestone.

All people and records in this project are fictional.
